## 📖 项目全景与核心愿景

**AI Radar** 是一套专为极客与创作者打造的 **7×24h 永远在线、高可用、零误报、完全自主自愈** 的 AI 科技早报自动化生成与全渠道矩阵分发系统。

系统每天破晓自动执行全网情报嗅探、大模型深度提炼、自适应报纸长图排版、云端低风控自动化发布以及移动桌面秒级分发，彻底摆脱人工搜集、排版搬运与本地电脑开机依赖。


## ✨ 核心突破与特色亮点

### 1. 🛡️ 独创“云端真实家庭环境深度伪装技术”（Stealth Residential Disguise）
云服务器在自动化操作中极易触发短视频平台的数据中心（IDC）IP、无头浏览器（Headless）指纹风控拦截。本项目研发了独特的云端环境隐形伪装层：
- **系统与平台伪装**：抹除 Linux 特征，全量注入 `Windows 10 x64` 系统标识与 `navigator.platform = "Win32"`。
- **显卡与 WebGL 欺骗**：将默认的虚拟渲染器（SwiftShader / llvmpipe）篡改为 `Google Inc. (NVIDIA)` 与 **NVIDIA GeForce RTX 3060 Direct3D11** 独立显卡指纹。
- **硬件与视口规格**：模拟真实家用 PC 的 **8核 CPU**、**8GB 内存** 与 **1920×1080 物理分辨率**。
- **浏览器运行时完整补齐**：补齐真实 Chrome 的 `window.chrome.runtime`、`app`、`csi` 等对象，彻底剔除 `navigator.webdriver` 标记。
- **原生 DOM 穿透直击**：采用 JavaScript 原生事件穿透触发发布按钮，100% 免疫 Linux/Windows 环境下的编码与文本乱码问题。
- **凭证冷备份硬保护机制**：采用只读消费模式，禁止发布异常时覆盖 Cookie，并实行本地与云端双重冷备份，保障免密运行长达数月。

### 2. 📱 安卓灵动磨砂玻璃桌面小组件（Android AppWidget）
- **极简科技美学**：采用原生 Android 开发（Kotlin），搭载现代磨砂毛玻璃背景（Frosted Glass UI）。
- **零等待秒级刷新**：直连 GitHub Gist 原生 CDN，清晨 07:15 准时自动刷新桌面列表。
- **无感交互**：无需打开臃肿 APP，桌面滑动即可速览最新 14 条全球科技动态，点击条目直达深度信息。
- **CI/CD 自动化构建**：内置 GitHub Actions 工作流，代码提交即自动打包产出 Release APK。

### 3. 🧠 智脑核心与智能前置去重
- **多源智能嗅探**：定向监控核心开发者动态、前沿大模型发布、算力芯片突破与地缘科技政策。
- **72h 历史指纹库**：维护 Rolling-window 历史标题与摘要指纹池，杜绝连续数天报道相似新闻。
- **Gemini 大模型精炼**：结构化输出高价值资讯，剔除公关废话，保留核心数据与行业影响。

### 4. 🐕 终局看门狗监控（Watchdog 巡检）
- **真正的去中心化监控**：监控节点独立部署在海外枢纽，不依赖发布机自身。
- **零骚扰静默法则**：发布成功时保持静默（0 骚扰邮件）；唯有任务超时或发布异常时才会触发紧急告警邮件，附带精准排查日志。

## 🚀 快速上手与部署指南

### 1. 环境依赖配置
推荐在 Python 3.10+ 环境下运行：
```bash
pip install -r requirements.txt
playwright install chromium
```

主要第三方库清单：
- `playwright` & `playwright-stealth`（无头浏览器与反爬对抗）
- `google-genai`（Google Gemini API 大模型调用）
- `Pillow`（自适应报纸卡片文字渲染）
- `paramiko`（跨节点高安全 SFTP 与 SSH 协同调度）

### 2. 环境变量配置
创建 `.env` 文件或配置系统环境变量：
```ini
# Gemini API Key
GEMINI_API_KEY="your_google_ai_studio_key"

# GitHub Gist 凭证 (供安卓小组件同步)
GITHUB_GIST_ID="your_gist_id"
GITHUB_GIST_TOKEN="your_github_personal_token"

# QQ 邮箱 SMTP 授权
SMTP_SERVER="smtp.qq.com"
SMTP_PORT=465
SMTP_USER="your_email@qq.com"
SMTP_PASS="your_smtp_auth_code"

# 跨节点协同凭据
KOREA_SERVER_IP="47.80.9.117"
KOREA_SERVER_PASS="your_vps_password"
```

### 3. Linux 节点 Crontab 调度配置

**节点 A：海外智脑枢纽（首尔 VPS）**
```cron
# 每天 07:15 CST 准时启动全网嗅探与提炼
15 7 * * * /usr/bin/python3 /root/ai_radar_job.py >> /root/ai_radar.log 2>&1

# 每天 07:45 CST 启动终局看门狗巡检
45 7 * * * /usr/bin/python3 /root/watchdog.py >> /root/watchdog.log 2>&1
```

**节点 B：国内发布机（阿里云 ECS）**
```cron
# 每天 07:25 CST 拉取任务并执行全套家庭伪装发布
25 7 * * * /usr/bin/python3 /root/ai_radar_publisher/publisher.py >> /root/ai_radar_publisher/publisher.log 2>&1
```

## 📱 安卓小组件安装体验

本仓库已配置 GitHub Actions 自动化编译工作流。
- **在线构建**：点击仓库页面顶部的 **Actions** -> **Build Android APK** -> 运行工作流即可下载最新 `app-debug.apk`。
- **本地编译**：
  ```bash
  cd android
  ./gradlew assembleDebug
  # 生成文件位于: android/app/build/outputs/apk/debug/app-debug.apk
  ```
